`scripts/generate-batch6-sql.ts` exports `generateBatch6Sql(baselinePath, outputPath, expectedBaselineSha256)`. Run with Node 24 and the installed `tsx` loader, from a checkout whose problem and roadmap source files match the pinned source. It reads the original 100 JSON files from pinned commit `1bacb2f947de89e92cb4fc08604132c1b78090e0`, validates the current 113 source problems and roadmap references, checks every original source hash against the supplied reviewed baseline, and writes SQL plus a manifest. The reviewed production baseline is `/tmp/algosprint-prod100-roadmap18-baseline-oct19.json`, SHA256 `b8aebbdd8b03291987948911034932c13a8693f79e80fa1a94404a30fea5a211`: 100 problem identities/hashes/statuses/revisions/timestamps and complete 18 roadmaps/307 ordered step identities and metadata. The SQL uses one explicit `BEGIN`/`COMMIT` transaction. Top-level `SET LOCAL` applies a 1-second lock timeout, 25-second statement timeout and 30-second transaction timeout before the `DO` statement begins; setting `statement_timeout` only inside the `DO` would not bound that running statement. It acquires administrator advisory 713013, roadmap advisory 712012, then the sorted 23 application tables in `SHARE ROW EXCLUSIVE` mode before baseline reads. Readers continue; application writes can briefly contend. Any timeout or conflict aborts the transaction. The exact application-table set and absence of unexpected insert triggers/rules are checked.

Only inserts into 13 content tables are permitted. All original problem metadata and normalized complete authored content, all original roadmap and step IDs/metadata, existing new-problem content, taxonomy references, and any existing capstone metadata/positions are checked before inserts. Identical additions skip; unrecognized existing problems/paths or conflicting additions abort the whole batch. Final contracts require 113 problems/19 paths/320 steps. Full preexisting rows of all 23 tables are compared inside the transaction after insertion; no old row may change or disappear, including private user history, notes, attempts, interviews, videos, taxonomy, starter IDs and relationships. Private rows never appear in the generated artifact, manifest or result notice.
