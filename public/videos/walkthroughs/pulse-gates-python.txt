A maintenance drone flies over a grid map. 'S' is its start, 'E' is the exit, '#' is

a wall, '.' is open floor, and a digit k is a pulse gate that is open only

at times t with t mod period = k (at every other time the gate acts like a

wall). The drone starts on S at time 0. Each tick (one unit of time) it either stays

in its cell or moves one cell up, down, left or right, and at the end of the

tick it must be standing on a cell that is open at that new time. Return the earliest

time at which the drone can be standing on E, or -1 if it never can.

The gate is open at odd times. The drone reaches the cell before the gate at time 1,

but at time 2 the gate is closed, so it waits one tick, enters the gate at time

3 (open) and steps onto E at time 4. The gate cell is the only way to E

(the cell below E is a wall) and the earliest the drone can stand there is time 2,

so waiting once is forced and the answer is 4.

A wall fills the whole third column, so the exit can never be reached and the answer is

-1.

Because the gates repeat, two arrivals at the same cell with the same time modulo period have identical

futures, so only the earliest one matters.

Run a breadth-first search whose states are (cell, time mod period). From each state try the five moves

to time + 1, accept a target that is in the grid, not '#', and either not a

gate or a gate whose digit equals (time + 1) mod period, and skip visited states. Return the

time of the first dequeued E, else -1.

Only time modulo the period matters, so the finite state space is rows × columns × period. Every

move costs one tick. Breadth-first search therefore

visits states in arrival-time order, and the first visit to E is optimal. A bytearray tracks visited states

compactly, and deque provides constant-time queue operations.

Start from the state (S, time mod 2 = 0). From it, staying put and stepping to (0,1)

are open at time 1.

The state ((0,1), 0) at time 2 comes from waiting one tick; from it the gate state ((0,2),

1) at time 3 is open, and E is dequeued at time 4.

O(rows * columns * period * 5), at most 1.8 million transitions. O(rows * columns * period) for

visited marks and the queue
